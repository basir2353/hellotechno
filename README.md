# Raya

Original GCC-first AI customer experience marketing site.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- EN / AR locale switching with RTL

## Run

```bash
cd raya
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

This is an **original** brand and copy set inspired by the AI CX category. It is not a clone of any third-party product site.
